# The 60-second GMI demonstration

This demonstration is designed for a repository video, LinkedIn, X and community posts. It uses synthetic data and makes no performance claim.

## The promise

One marketing question enters. Evidence, calculations, competing perspectives and a human-controlled decision come out.

## Run it locally

```bash
git clone https://github.com/Gourav2411/general-marketing-intelligence.git
cd general-marketing-intelligence
npm ci
npm run build
npm run demo -- growth-bet
```

## 60-second script and shot list

### 0–6 seconds: the problem

**On screen:** GA4, Search Console, ad-platform and CRM cards pull away from one another.

**Voiceover:** “Marketing does not have a dashboard problem. It has a decision problem.”

### 6–13 seconds: the question

**On screen:** A single prompt appears: “Where should the next month of acquisition effort go?”

**Voiceover:** “I wanted one place where an AI could inspect the evidence without inventing the numbers.”

### 13–23 seconds: the evidence layer

**On screen:** Search, analytics, paid-media and CRM rows flow into one provenance-bearing evidence stream.

**Voiceover:** “GMI connects search, analytics, ads and CRM data. Retrieval, joins and calculations happen in code.”

### 23–34 seconds: the diagnosis

**On screen:** Search A shows 6.43x pipeline-to-spend and Social B shows 3.81x. Labels distinguish observed, calculated and proposed values.

**Voiceover:** “It separates observed facts from calculated metrics, assumptions and recommendations, so a confident sentence cannot disguise weak evidence.”

### 34–44 seconds: intelligence with disagreement

**On screen:** Nine evaluator cards vote, disagree and converge on a bounded test.

**Voiceover:** “Nine independent evaluators challenge the recommendation, retrieve relevant precedents and expose disagreement instead of hiding it.”

### 44–53 seconds: human approval

**On screen:** Recommendation: “Increase Search A by no more than 10%.” A locked approval gate remains between the recommendation and the advertising platform.

**Voiceover:** “The system can recommend a test. It cannot quietly change a budget. Consequential actions remain behind explicit human approval.”

### 53–60 seconds: invitation

**On screen:** Repository cover, Apache-2.0 badge and the words “Run it. Challenge it. Improve it.”

**Voiceover:** “General Marketing Intelligence is open source. Run it, challenge it, and star it if this is how marketing AI should work.”

## Recording checklist

- Record at 1080p with the terminal font large enough for mobile viewers.
- Show the command and result, not credential setup or private data.
- Keep all figures visibly labelled as synthetic.
- Do not imply incrementality where the example only shows attributed outcomes.
- End on the repository URL for at least three seconds.
- Use captions; most social viewers begin with sound disabled.

## Repository call to action

> Try the synthetic demo in under a minute. If the evidence boundaries and human-approval model are useful, star the repository and open a testing report with what worked, what failed and what you expected instead.
