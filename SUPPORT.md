# Support

Use GitHub Discussions, if enabled, for usage questions and GitHub Issues for reproducible defects or scoped feature requests. This community project provides no guaranteed response time, uptime, support level or warranty.

Before asking for help, remove credentials and sensitive business data, run `npm run verify`, and include your operating system, Node.js version, client, relevant sanitized logs and exact reproduction steps.

Report security vulnerabilities privately as described in `SECURITY.md`.
