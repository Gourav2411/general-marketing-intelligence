# Governance

General Marketing Intelligence currently follows a maintainer-led governance model.

## Maintainer

- Gourav Kondadadi (`@Gourav2411`)

The maintainer sets project direction, reviews and merges contributions, manages releases and security responses, and may delegate responsibilities to future maintainers.

## Trusted reviewers

Trusted reviewers may be granted repository access for independent pull-request, corpus, security or release review. Appointment requires a public GitHub identity, demonstrated relevant judgment, acceptance of the Code of Conduct and explicit approval from the maintainer. Review authority does not grant release, credential or administrative authority unless separately documented.

At least two trusted humans should review changes involving credentials, hosted tenant isolation, external mutations, licensing or disputed corpus rights when practical. The current reviewer roster is recorded in `CODEOWNERS`; adding a reviewer requires a reviewed pull request rather than an undocumented access grant.

## Decisions

Routine decisions are made through issues and pull-request review. Changes affecting licensing, security boundaries, credential handling, deterministic calculations, data contracts, backward compatibility or governance require explicit maintainer approval.

There is no entitlement to merge, maintainership or release authority based solely on contribution volume. Governance changes will be documented in this file.
